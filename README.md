# Jogo: "O chão é lava"

## Descrição do jogo

"O chão é lava" é um jogo de plataforma 2D desenvolvido em Python com Pygame, inspirado em jogos de parkour vertical simples e na brincadeira de não encostar no chão para "fugir da lava". No jogo, o jogador controla uma escaladora que precisa alcançar a bandeira no topo de cada fase antes que a lava a alcance. Cada fase possui 25 plataformas com posições e larguras variadas: as laranjas são estáveis, enquanto as vermelhas quebram dois segundos após serem pisadas. A dificuldade aumenta ao longo das fases, com lava mais rápida e maior presença de plataformas frágeis. O jogador começa cada fase com três vidas e, ao tocar na lava, perde uma delas e retorna à plataforma mais alta já alcançada, caso ainda tenha vidas disponíveis.

## Como jogar e instalações
No menu inicial, clique em “Jogar” e pressione espaço na tela de instruções. Os controles são: A/D ou setas laterais para movimentar, espaço ou seta para cima para pular, R para avançar após concluir uma fase ou reiniciar na fase 1 após perder todas as vidas, e Esc para sair. Para executar o projeto, é necessário ter instalado o Python 3 e o Pygame, além das imagens da página do código: imagem2.png, imagem3.png, lava.png, escaladora_direita.png, escaladora_esquerda.png e escaladora_pulo.png (formam a interface do jogo).
